Science Game Shows

Classroom game shows that run in a browser, with no accounts and nothing to install. Pick an edition and a game. Each one opens a host screen and can show a second screen for contestants.

  • Category BoardA 5 by 5 board of categories and point values.
  • Bluffing TriviaWhich one is real? One true answer hides among plausible fakes.
